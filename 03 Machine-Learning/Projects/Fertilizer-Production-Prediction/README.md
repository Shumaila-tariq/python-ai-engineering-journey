# Fertilizer Production Prediction

## Project Overview
This project demonstrates a machine learning application for fertilizer production prediction. It uses a trained model and a Streamlit interface to accept input and display predictions.

## Technologies Used
- Python
- Scikit-learn
- Streamlit
- NumPy
- Pandas
- Joblib

## Project Files
- `app.py` - Streamlit application
- `fertilizers.csv` - Dataset used by the project
- `model.pkl` - Trained machine learning model
- `requirements.txt` - Required Python libraries

## Installation

1. Install Python.
2. Open a terminal in this project folder.
3. Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```
